the best part

Send it. It sorts itself.

Other clients make you name, file, and save everything by hand. Pigeon does the librarian work while you work.

Tabs name themselves

New tabs auto-derive their name from the URL path and follow it as you type. Rename one manually and it locks — your name wins.

Requests file themselves

Every send is auto-saved as a draft and filed into a path-compressed tree — one folder per domain, grouped by endpoint. No "save as…" dialog, ever.

History writes itself

Every request lands in a time-bucketed log — Today, Yesterday, This Week — with method, name, and status. Search it all with ⌘F.

features

Everything you need. Nothing you don't.

A focused toolset for testing REST APIs — built for speed, not for upselling you a workspace plan.

Request builder

Tabs with color-coded methods, a smart URL bar, and clean editors for params, auth, headers, and body — JSON to multipart.

Native speed

A Rust engine sends your requests — no CORS pain, full control over redirects, SSL verification, and proxies. Starts instantly.

Environments

{{var}} sets for dev, staging, and prod — with secret masking and red production guardrails so you never hit prod by accident.

Collections on your terms

Auto-organization handles the daily grind; curated collections (⌘S) are there when you want deliberate structure. All stored locally.

cURL in & out

Paste any curl command and Pigeon builds the request instantly. Copy any request back as cURL to share with your team.

Keyboard-first

Send with ⌘↵, manage environments with ⌘⇧E, and fly through everything else with a full shortcut reference (⌘/).

why pigeon

API clients got heavy. We went the other way.

→No account, ever

Open the app and send a request. No sign-up walls, no workspace invitations, no "sync to continue".

→Local by default

Collections, history, and environments live on your disk. Your API keys never touch anyone's cloud.

→Native, not Electron

Built with Tauri and Rust — a fraction of the memory and disk footprint of browser-in-a-box API clients.

open source

Built in the open. Owned by no one.

Pigeon is MIT-licensed and developed publicly on GitHub. Every feature, every fix, every decision — out in the open. If it doesn't do what you need, you can change it. That's the point.
