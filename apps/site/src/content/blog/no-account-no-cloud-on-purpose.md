A lot of API clients greet you with a sign-in. Then a workspace. Then a sync reminder. Then an update that wants the cloud again.

Pigeon skips that stack. Open the app. Type a URL. Hit send. There's no account to create and no team space to join.

## What stays local

Collections, history, environments, and the keys you paste into them live on your disk. That's the default — not an advanced setting buried in preferences.

## What you give up

Cross-device sync out of the box. If you need the same collection on another machine, export it. We think that's a fair trade for keeping API keys off someone else's servers.

Native app. Local data. Send a request and move on.
